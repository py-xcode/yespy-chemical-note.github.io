    总结：必修一所有反应

    1.1 根据物质的组成和性质分类
    氧化物：和酸/碱反应生成盐和水，和碱性氧化物生成盐，能溶于水的和水反应生成对应的酸和碱。
    不溶于水的碱性氧化物遇热分解，生成水和对应的金属氧化物。（碱性氧化物一定是金属氧化物）
    1.2 分散系及其分类
    胶体制备：\(\ce{FeCl3 + 3H2O ->[\triangle] Fe(OH)3（胶体） + 3HCl}\)。
    1.3 酸、碱、盐性质+物质的转化

    3 氧化还原反应 导引
    氧化还原反应
    4.1 钠元素+钠单质+钠的氧化物
    Na
    1.和氧气反应，生成氧化纳/过氧化钠
    2.和非金属单质反应生成无氧酸盐
    3.和水反应：浮熔游响红
    4.和强酸：发生置换
    5.和盐：水环境下先和水反应，NaOH再和盐反应；非水环境下发生置换。
    Na的氧化物
    氧化纳（碱性氧化物）：
    1.和水生成氢氧化钠
    2.和二氧化碳生成碳酸钠（酸性氧化物和碱性氧化物反应）
    3.和酸中的氢离子反应生成钠离子和水
    4.加热条件下和氧气反应生成过氧化钠（制取过氧化钠）

    过氧化钠：
    1.和水生成氢氧化钠和氧气
    2.和二氧化碳反应生成碳酸钠和氧气
    3.和酸中的氢离子反应生成钠离子、水和氧气

    注意

    \(\ce{Na2O2}\)与水蒸气，\(\ce{CO2}\)的混合物反应时，优先和\(\ce{CO2}\)反应，再和水蒸气反应。

    4.2 碳酸钠+碳酸氢钠
    碳酸钠
    1.在水溶液中和二氧化碳反应生成碳酸氢钠。
    2.和稀硫酸反应，碳酸根先变成碳酸氢根，碳酸氢根再变成二氧化碳和水。
    3.和氢氧化钡反应，生成碳酸钡和水。

    碳酸氢钠
    1.遇热分解生成碳酸钠，二氧化碳和水。
    2.和稀硫酸反应，生成二氧化碳和水。
    3.和少量氢氧化钡反应生成碳酸钡沉淀，碳酸根离子和水；和过量氢氧化钡反应生成碳酸钡和水。
    4.和氢氧化钠反应生成碳酸根和水。

    5.1 氯气的性质、用途、制备与检验
    Cl₂
    1.和金属单质反应：钠在氯气中燃烧生成白烟，铁燃烧生成氯化铁棕褐色烟，铜燃烧生成氯化铜棕黄色烟。
    2.和非金属单质反应：在氢气中安静的燃烧发出苍白色火焰，有白雾，生成氯化氢；磷燃烧生成白色的烟和雾：\(\ce{2P + 3Cl2 ->[\Delta] 2PCl3}\)(液体)、\(\ce{PCl3 + Cl2 <=> PCl5}\)(固体)。
    3.和水反应，制取氯水。\(\ce{Cl2 ​+ H2​O<=>H+ +Cl− + HClO}\)  生成物“三分四离”：\(\ce{H2O}\)>\(\ce{Cl2}\)>\(\ce{HClO}\)；\(\ce{H+}\)>\(\ce{Cl-}\)>\(\ce{ClO-}\)>\(\ce{OH-}\)
    新制氯水光照下分解，变成稀盐酸（次氯酸见光分解，生成氯化氢和氧气。
    4.和碱反应（制取漂白液漂白粉）
    i.漂白液（主要成分氯化钠和次氯酸钠）
    制取：氯气和氢氧化钠反应，生成氯化钠，次氯酸钠和水。
    生效：次氯酸钠和二氧化碳、水反应，生成碳酸氢钠和次氯酸（漂白性，强氧化性）
    变质：次氯酸见光分解（同上）
    ii.漂白粉（主要成分氯化钙和次氯酸钙）
    制取：氯气和氢氧化钙（冷的石灰乳）反应，生成氯化钙，次氯酸钙和水
    生效：次氯酸钙和二氧化碳、水反应，生成碳酸钙和次氯酸（漂白性，强氧化性）

    注意

    在二氧化碳多时，此反应生成Ca(HCO₃)₂、HClO。

    变质：同上
    84消毒液和洁厕灵混合产生氯气：NaClO + 2HCl = NaCl + Cl₂↑ + H₂O（危险！危险！）
    5.氧化还原反应

    反应对象 化学方程式 离子方程式
    与 H₂S 溶液反应 \(Cl_2 + H_2S = S\downarrow + 2HCl\) \(Cl_2 + H_2S = S\downarrow + 2H^+ + 2Cl^-\)
    与 SO₂ 水溶液反应 \(Cl_2 + SO_2 + 2H_2O = 2HCl + H_2SO_4\) \(Cl_2 + SO_2 + 2H_2O = 4H^+ + 2Cl^- + SO_4^{2-}\)
    与 KI 溶液反应 \(Cl_2 + 2KI = I_2 + 2KCl\) \(Cl_2 + 2I^- = I_2 + 2Cl^-\)
    与 KBr 溶液反应 \(Cl_2 + 2KBr = Br_2 + 2KCl\) \(Cl_2 + 2Br^- = Br_2 + 2Cl^-\)
    与 FeCl₂ 溶液反应 \(Cl_2 + 2FeCl_2 = 2FeCl_3\) \(Cl_2 + 2Fe^{2+} = 2Fe^{3+} + 2Cl^-\)
    与 NH₃ 反应 \(8NH_3 + 3Cl_2 = N_2 + 6NH_4Cl\)（\(NH_4Cl\) 是白色固体颗粒，其分散在空气中形成白烟，可用浓氨水检验运输液氯的管道是否漏气） （气相反应，无离子方程式）

    6. 和氢氧化钠反应，吸收氯气：\(\ce{Cl2 ​+ 2NaOH -> NaCl + NaClO + H2​O}\)
    制取\(Cl_2\)
    1.用二氧化锰制取
    化学方程式：\(MnO_2 + 4HCl(浓) \xlongequal{\Delta} MnCl_2 + Cl_2 \uparrow + 2H_2O\)
    离子方程式：\(MnO_2 + 4H^+ + 2Cl^- \xlongequal{\Delta} Mn^{2+} + Cl_2 \uparrow + 2H_2O\)
    2.用高锰酸钾制取
    \(2KMnO_4 + 16HCl = 2MnCl_2 + 2KCl + 5Cl_2 \uparrow + 8H_2O\)，
    离子方程式为 \(2MnO_4^- + 16H^+ + 10Cl^- = 2Mn^{2+} + 5Cl_2 \uparrow + 8H_2O\)。
    注意，NaClO + 2HCl = NaCl + Cl₂↑ + H₂O（84消毒液和洁厕灵混合生成氯气）这个反应也可以生成\(Cl_2\)。
    3.电解氯化钠水溶液
    \(\ce{2NaCl + 2H2​O}\)  在电解条件下生成  \(​2\ce{NaOH + H2​↑ + Cl2​↑}\)

    拓展 溴离子和碘离子和Ag反应，生成溴化银（淡黄色沉淀），碘化银（黄色沉淀）。

    7.1 铁单质+铁的氧化物
    1.和空气中的氧反应
    i.生成铁锈\(Fe_2O_3 \cdot xH_2O\)
    ii.纯氧中点燃生成四氧化三铁
    2.和氯气反应生成氯化铁（注意不是亚铁）
    3.和硫反应生成硫化亚铁（注意是亚铁）
    4.和水蒸汽在高温下生成四氧化三铁和氢气。
    5.和酸反应
    i. 盐酸或稀硫酸：\(Fe + 2H^+ = Fe^{2+} + H_2 \uparrow\)
    （Fe 与非氧化性酸，如稀硫酸、盐酸等反应，不管酸量多，还是酸量少，只能生成亚铁盐）
    ii. 稀硝酸：铁与足量稀硝酸：\(\overset{0}{Fe} + 4H\overset{+5}{N}O_{3}(稀) = \overset{+3}{Fe}(NO_{3})_{3} + \overset{+2}{N}O\uparrow + 2H_{2}O\)
    （硝酸具有强氧化性，能够把铁氧化成三价铁。）
    iii. 足量铁和稀硝酸：（铁先和稀硝酸反应，之后生成的三价铁和铁单质反应生成二价铁）
    \(3\overset{0}{Fe} + 8H\overset{+5}{N}O_3(稀) = 3\overset{+2}{Fe}(NO_3)_2 + 2\overset{+2}{N}O\uparrow + 4H_2O\)
    iv. 常温下，铁和浓硝酸或浓硫酸：钝化反应
    v. 加热下，铁和浓硝酸或浓硫酸：
    \(2\overset{0}{Fe} + 6H_2\overset{+6}{S}O_4(浓) \xlongequal{\Delta} \overset{+3}{Fe}_2(SO_4)_3 + 3\overset{+4}{S}O_2\uparrow + 6H_2O\)
    \(\overset{0}{Fe} + 6H\overset{+5}{N}O_3(浓) \xlongequal{\Delta} \overset{+3}{Fe}(NO_3)_3 + 3\overset{+4}{N}O_2\uparrow + 3H_2O\)
    6.炼铁
    \(Fe_2O_3 + 3CO \xlongequal{高温} 2Fe + 3CO_2\)
    （磁铁矿同理）
    （此外，铝热反应同样可以用于炼铁）

    铁的氧化物

    物质 氧化亚铁(\(FeO\)) 氧化铁(\(Fe_2O_3\)) 四氧化三铁(\(Fe_3O_4\))
    与 \(CO\) 反应 \(FeO + CO \xlongequal{高温} Fe + CO_2\) \(Fe_2O_3 + 3CO \xlongequal{高温} 2Fe + 3CO_2\) \(Fe_3O_4 + 4CO \xlongequal{高温} 3Fe + 4CO_2\)
    与盐酸或稀硫酸（氢离子）反应 \(FeO + 2H^+ = Fe^{2+} + H_2O\) \(Fe_2O_3 + 6H^+ = 2Fe^{3+} + 3H_2O\) \(Fe_3O_4 + 8H^+ = Fe^{2+} + 2Fe^{3+} + 4H_2O\)
    与稀硝酸反应（氧化性） \(3FeO + 10HNO_3(稀) = 3Fe(NO_3)_3 + NO\uparrow + 5H_2O\) \(Fe_2O_3 + 6H^+ = 2Fe^{3+} + 3H_2O\) \(3Fe_3O_4 + 28HNO_3(稀) = 9Fe(NO_3)_3 + NO\uparrow + 14H_2O\)
    与氢碘酸反应（还原性） \(FeO + 2HI = FeI_2 + H_2O\) \(Fe_2O_3 + 6HI = 2FeI_2 + I_2 + 3H_2O\) \(Fe_3O_4 + 8HI = 3FeI_2 + I_2 + 4H_2O\)

    \(FeO\) 不稳定，在空气中受热，能迅速被氧化成 \(Fe_3O_4\)，对应化学方程式为 \(6FeO + O_2 \xlongequal{\Delta} 2Fe_3O_4\)。
    总结：高中范围内产物是\(\ce{Fe3O4}\)的反应：
    ①\(3Fe + 2O_2 \xrightarrow{点燃} Fe_3O_4\)
    ②\(3Fe + 4H_2O(g) \xlongequal{高温} Fe_3O_4 + 4H_2\)
    ③ \(6FeO + O_2 \xlongequal{\Delta} 2Fe_3O_4\)

    铁的其他化合物
    氢氧化亚铁：
    1.和盐酸/稀硫酸反应
    2.遇热分解：隔绝空气时\(Fe(OH)_2 \xlongequal{\Delta} FeO + H_2O\) ；空气中加热\(4Fe(OH)_2 + O_2 \xlongequal{\Delta} 2Fe_2O_3 + 4H_2O\) （铁被氧化）
    3.在空气中被氧化成氢氧化铁，白色絮状沉淀迅速转化成灰绿色，最后变成红褐色。化学方程式为 \(4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3\)。

    氢氧化铁：
    1.和盐酸/稀硫酸反应
    2.遇热分解：\(2Fe(OH)_3 \xlongequal{\Delta} Fe_2O_3 + 3H_2O\)

    铁盐和亚铁盐：

    对象 \(Fe^{2+}\) \(Fe^{3+}\)
    反应 (1) 复分解反应
    ① 与 \(OH^-\) 沉淀：\(Fe^{2+} + 2OH^- = Fe(OH)_2 \downarrow\)
    ② 与 \(CO_3^{2-}\) 沉淀：\(Fe^{2+} + CO_3^{2-} = FeCO_3 \downarrow\)    		 (1) 复分解反应
    与 \(OH^-\) 沉淀：\(Fe^{3+} + 3OH^- = Fe(OH)_3 \downarrow\)
    化学性质 (2) 氧化还原反应
    ① 与氧化剂反应（体现强还原性）
    i. \(2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-\)（除去 \(FeCl_3\) 中的 \(FeCl_2\)）
    ii. \(2Fe^{2+} + H_2O_2 + 2H^+ = 2Fe^{3+} + 2H_2O\)（除去 \(Fe^{3+}\) 中的 \(Fe^{2+}\)）
    iii. \(3Fe^{2+} + NO_3^- + 4H^+ = 3Fe^{3+} + NO\uparrow + 2H_2O\)（酸性条件下 \(Fe^{2+}\) 与 \(NO_3^-\) 不能大量共存）
    iv. \(6Fe^{2+} + Cr_2O_7^{2-} + 14H^+ = 6Fe^{3+} + 2Cr^{3+} + 7H_2O\)（除去污水中的 \(Cr_2O_7^{2-}\)）
    v. \(5Fe^{2+} + MnO_4^- + 8H^+ = 5Fe^{3+} + Mn^{2+} + 4H_2O\)（检验 \(Fe^{2+}\) 的还原性）
    ② 与还原剂反应（体现弱氧化性）
    \(Fe^{2+} + Zn = Zn^{2+} + Fe\)    		 (2) 氧化还原反应：与还原剂反应（体现较强氧化性）
    ① \(2Fe^{3+} + Fe = 3Fe^{2+}\)（除 \(Fe^{2+}\) 中的 \(Fe^{3+}\)）
    ② \(2Fe^{3+} + Cu = 2Fe^{2+} + Cu^{2+}\)（用 \(Fe^{3+}\) 腐蚀 \(Cu\)，制作印刷电路板）
    ③ \(2Fe^{3+} + S^{2-}\)（少量）\(= 2Fe^{2+} + S\downarrow\)
    ④ \(2Fe^{3+} + SO_3^{2-} + H_2O = 2Fe^{2+} + SO_4^{2-} + 2H^+\)
    ⑤ \(2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2\)
    (3) 显色反应
    \(Fe^{3+} + 3SCN^- \rightleftharpoons Fe(SCN)_3\)（红色溶液）
