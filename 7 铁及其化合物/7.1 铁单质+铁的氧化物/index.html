    7.1 铁单质+铁的氧化物¶

    A.铁单质¶

    a.自然界存在 铁元素在自然界中几乎都以化合物的形式存在（但铁在自然界中可以像陨铁中的铁那样以单质形态存在，因此铁元素在自然界是有游离态的）。铁元素在地壳中的含量居第四位，前三位的元素依次是 \(O\)、\(Si\)、\(Al\)。
    b.人体中的铁元素 铁元素是人体必需微量元素中含量最多的一种，功能性铁元素主要参与氧的运输。为了减少缺铁性贫血，可以食用铁强化酱油 。
    c.铁的化合价 铁的常见化合价有 \(0\)、\(+2\)、\(+3\)，用于净水的 \(K_2FeO_4\)（高铁酸钾）中，铁元素的化合价为 \(+6\)。
    d.物理性质 在常温下，纯净的铁块为银白色（铁的合金以及铁粉一般为黑色）具有金属光泽的固体，能导电和导热，具有延展性和磁性 。
    e.化学性质
      根据金属活动性顺序表可知，铁单质具有较强的还原性，能与很多氧化剂反应。
      1.与非金属单质的反应
      ① 与 \(O_2\) 反应
      i. 常温下暴露在空气中的生铁容易发生吸氧腐蚀，铁锈的主要成分为 \(Fe_2O_3 \cdot xH_2O\)（常温下，潮湿环境利于铁的腐蚀，所以减少铁的腐蚀措施之一是保持其干燥）。
      ii. 在纯氧中点燃：\(3Fe + 2O_2 \xrightarrow{点燃} Fe_3O_4\)

    注意

    这两个反应体现了温度的“量变引起质变”。

      ② 与 \(Cl_2\) 反应：\(2Fe + 3Cl_2 \xlongequal{\Delta} 2FeCl_3\)（或点燃）

    注意

    强氧化性的 \(Cl_2\) 与 \(Fe\) 反应只能生成 \(+3\) 价的铁盐，无量变引起质变。铁可以和\(\ce{FeCl3}\)反应生成\(\ce{FeCl2}\)，但是这个反应只能在溶液中进行，而\(2Fe + 3Cl_2 \xlongequal{\Delta} 2FeCl_3\)不在溶液中进行，因此除非将反应后的产物溶解在水中，否则不会产生\(\ce{FeCl2}\)。

      ③ 与 \(S\) 反应：\(Fe + S \xlongequal{\Delta} FeS\)
      注：\(S\) 的氧化性较弱，铁与 \(S\) 反应只能生成 \(+2\) 价的亚铁盐，无量变引起质变。
      同理，遇到\(\ce{Br2}\)、\(I_2\)等物质也会生成对应的无氧酸盐，其中\(Cl_2、Br_2\)这类氧化性强的物质能够把铁氧化到+3价，\(I_2、S\)这些氧化性比较弱的物质只能把铁氧化到+2价。
      2.与化合物的反应

    反应物 反应及注解
    与水蒸气 \(3Fe + 4H_2O(g) \xlongequal{高温} Fe_3O_4 + 4H_2\)
    (g)指气态
    （记忆方法：三思三思（3434），第一个“三思（34）”指反应物化学计量数，第二个“三思（34）”指四氧化三铁的小角标。）
    与酸 i. 盐酸或稀硫酸：\(Fe + 2H^+ = Fe^{2+} + H_2 \uparrow\)
    （Fe 与非氧化性酸，如稀硫酸、盐酸等反应，不管酸量多，还是酸量少，只能生成亚铁盐）
    ii. 稀硝酸：铁与足量稀硝酸：\(\overset{0}{Fe} + 4H\overset{+5}{N}O_{3}(稀) = \overset{+3}{Fe}(NO_{3})_{3} + \overset{+2}{N}O\uparrow + 2H_{2}O\)
    （硝酸具有强氧化性，能够把铁氧化成三价铁。）
    iii. 足量铁和稀硝酸：（铁先和稀硝酸反应，之后生成的三价铁和铁单质反应生成二价铁）
    \(3\overset{0}{Fe} + 8H\overset{+5}{N}O_3(稀) = 3\overset{+2}{Fe}(NO_3)_2 + 2\overset{+2}{N}O\uparrow + 4H_2O\)
    iv. 常温下，铁和浓硝酸或浓硫酸：钝化反应
    v. 加热下，铁和浓硝酸或浓硫酸：
    \(2\overset{0}{Fe} + 6H_2\overset{+6}{S}O_4(浓) \xlongequal{\Delta} \overset{+3}{Fe}_2(SO_4)_3 + 3\overset{+4}{S}O_2\uparrow + 6H_2O\)
    \(\overset{0}{Fe} + 6H\overset{+5}{N}O_3(浓) \xlongequal{\Delta} \overset{+3}{Fe}(NO_3)_3 + 3\overset{+4}{N}O_2\uparrow + 3H_2O\)
    与盐 \(Fe + 2Fe^{3+} = 3Fe^{2+}\)（归中反应） ; \(Fe + Cu^{2+} = Cu + Fe^{2+}\)（湿法冶铜）

      注：铁和 \(Cl_2\)、\(O_2\) 反应需要一定的引发条件，要么需要水的存在，要么需要一定的温度。常温下，铁和干燥的 \(Cl_2\)、\(O_2\) 均不反应，所以液氯、液氧可以保存在钢瓶中。

    注意

    钝化反应发生的条件：①铁或铝 ②冷或常温 ③浓硫酸或浓硝酸 。钝化反应的原理是由于反应过快，迅速形成了一层具有抗腐蚀性的氧化物薄膜，使得反应停止。因此，钝化反应不是不反应，只是反应会快速停止，不持续反应。加热会破坏钝化氧化膜，因此加热不会发生钝化反应。

    f.重点实验——铁与水蒸气反应的实验
      1.原理：\(3Fe + 4H_2O(g) \xlongequal{高温} Fe_3O_4 + 4H_2\)
      2.装置图：
      
      注：①湿棉花用于提供水蒸气。②还原性铁粉下的酒精灯可用酒精喷灯替换。③肥皂液用于收集氢气。
      3.现象：用火柴点燃肥皂泡，听到爆鸣声。
      4.结论：铁与水蒸气反应，生成可燃性气体 \(H_2\)。

    注意

    这个反应生成的氢气易燃易爆，因此需要尾气处理。

    g.用途
      (1) 铁的合金是良好的建筑材料；
      (2) 用于其他金属的冶炼。
    h.冶炼——高炉炼铁（热还原法）
      \(Fe_2O_3 + 3CO \xlongequal{高温} 2Fe + 3CO_2\)
      注：原料可以是赤铁矿（主要成分是 \(Fe_2O_3\)），也可以是磁铁矿（主要成分是 \(Fe_3O_4\)）。

    B.铁的氧化物¶

    物质 氧化亚铁(\(FeO\)) 氧化铁(\(Fe_2O_3\)) 四氧化三铁(\(Fe_3O_4\))
    类别 碱性氧化物 碱性氧化物 ——
    俗名 —— 铁红 磁性氧化铁
    色、态 黑色粉末 红棕色粉末 黑色晶体
    溶解度(水) 难溶 难溶 难溶
    \(Fe\) 的化合价 \(+2\) \(+3\) \(一个+2、两个+3\)
    与 \(CO\) 反应 \(FeO + CO \xlongequal{高温} Fe + CO_2\) \(Fe_2O_3 + 3CO \xlongequal{高温} 2Fe + 3CO_2\) \(Fe_3O_4 + 4CO \xlongequal{高温} 3Fe + 4CO_2\)
    与盐酸或稀硫酸（氢离子）反应 \(FeO + 2H^+ = Fe^{2+} + H_2O\) \(Fe_2O_3 + 6H^+ = 2Fe^{3+} + 3H_2O\) \(Fe_3O_4 + 8H^+ = Fe^{2+} + 2Fe^{3+} + 4H_2O\)
    用途 冶炼铁 冶炼铁、颜料 冶炼铁、磁铁
    与稀硝酸反应（氧化性） \(3FeO + 10HNO_3(稀) = 3Fe(NO_3)_3 + NO\uparrow + 5H_2O\) \(Fe_2O_3 + 6H^+ = 2Fe^{3+} + 3H_2O\) \(3Fe_3O_4 + 28HNO_3(稀) = 9Fe(NO_3)_3 + NO\uparrow + 14H_2O\)
    与氢碘酸反应（还原性） \(FeO + 2HI = FeI_2 + H_2O\) \(Fe_2O_3 + 6HI = 2FeI_2 + I_2 + 3H_2O\) \(Fe_3O_4 + 8HI = 3FeI_2 + I_2 + 4H_2O\)

    注意

    \(FeO\) 不稳定，在空气中受热，能迅速被氧化成 \(Fe_3O_4\)，对应化学方程式为 \(6FeO + O_2 \xlongequal{\Delta} 2Fe_3O_4\)。

    总结：高中范围内产物是\(\ce{Fe3O4}\)的反应：
    ①\(3Fe + 2O_2 \xrightarrow{点燃} Fe_3O_4\)
    ②\(3Fe + 4H_2O(g) \xlongequal{高温} Fe_3O_4 + 4H_2\)
    ③ \(6FeO + O_2 \xlongequal{\Delta} 2Fe_3O_4\)
