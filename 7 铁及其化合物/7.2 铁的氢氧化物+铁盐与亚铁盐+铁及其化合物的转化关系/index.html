    7.2 铁的氢氧化物+铁盐与亚铁盐+铁及其化合物的转化关系¶

    A.铁的氢氧化物¶

    \(Fe(OH)_2\) \(Fe(OH)_3\)
    色、态 白色固体 红褐色固体
    溶解度(水) 难溶 难溶，溶解度比 \(Fe(OH)_2\) 更小
    化合价 \(+2\) \(+3\)
    化性 碱性、强还原性、受热不稳定性 碱性、受热不稳定性
    与盐酸或稀硫酸反应 \(Fe(OH)_2 + 2H^+ = Fe^{2+} + 2H_2O\) \(Fe(OH)_3 + 3H^+ = Fe^{3+} + 3H_2O\)
    加热 隔绝空气加热：\(Fe(OH)_2 \xlongequal{\Delta} FeO + H_2O\)
    空气中加热：\(4Fe(OH)_2 + O_2 \xlongequal{\Delta} 2Fe_2O_3 + 4H_2O\) （铁被氧化）    		 \(2Fe(OH)_3 \xlongequal{\Delta} Fe_2O_3 + 3H_2O\)

    二者关系：在空气中，\(Fe(OH)_2\) 能够非常迅速地被氧气氧化成 \(Fe(OH)_3\)，现象是白色絮状沉淀迅速转化成灰绿色，最后变成红褐色，化学方程式为 \(4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3\)。
    a.氢氧化亚铁的制备
      1.原理：可溶性亚铁盐（\(FeCl_2\)、\(FeSO_4\) 等）和强碱（\(NaOH\)）发生复分解反应，反应的离子方程式为 \(Fe^{2+} + 2OH^- = Fe(OH)_2 \downarrow\)。
      2.关键点：防止 \(Fe(OH)_2\) 被氧化
      3.防氧化的措施
      ① 配制溶液的蒸馏水要煮沸，目的是除去水中溶解的氧气（气体溶解度与温度负相关）。
      ② 胶头滴管伸入液面以下滴加液体（其他实验中，胶头滴管应该竖直悬空，不能伸进容器）。
      ③ 液体表面加植物油（或苯）隔绝氧气。
    b.常用的改进装置及其工作原理

    装置 原理 操作
    先在装置Ⅰ中生成 \(FeSO_4\) 溶液，并利用生成的 \(H_2\) 将装置内的空气排尽后，再把生成的 \(FeSO_4\) 溶液压入装置Ⅱ中与 \(NaOH\) 溶液混合，这样可长时间观察到白色沉淀 ①先检查装置的气密性；②加入试剂，并打开弹簧夹 a；③收集 B 出口的气体并验纯；④再关闭弹簧夹 a

      【总结】 制备强还原性物质时，常采用以下措施防氧化：
      i. 通过煮沸将溶液中溶解的 \(O_2\) 除去。
      ii. 用惰性气体或还原性气体排除空气并形成保护气，保护气一般“先来后走”。
      iii. 在水溶液表面加植物油或矿物油，隔绝空气。
      iv. 往体系中添加还原性更强的保护剂（如配制 \(FeSO_4\) 溶液时，可以往 \(FeSO_4\) 溶液中加入 \(Fe\) 粉）。

    B.铁盐与亚铁盐¶

    a.组成和性质对比

    对象 \(Fe^{2+}\) \(Fe^{3+}\)
    代表 \(FeSO_4 \cdot 7H_2O\)（绿色固体）（绿矾） \(FeCl_3\)（棕色固体）
    颜色 浅绿色（溶液） （棕）黄色（溶液）
    反应 (1) 复分解反应
    ① 与 \(OH^-\) 沉淀：\(Fe^{2+} + 2OH^- = Fe(OH)_2 \downarrow\)
    ② 与 \(CO_3^{2-}\) 沉淀：\(Fe^{2+} + CO_3^{2-} = FeCO_3 \downarrow\)    		 (1) 复分解反应
    与 \(OH^-\) 沉淀：\(Fe^{3+} + 3OH^- = Fe(OH)_3 \downarrow\)
    对象 \(Fe^{2+}\) \(Fe^{3+}\)
    化学性质 (2) 氧化还原反应
    ① 与氧化剂反应（体现强还原性）
    i. \(2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-\)（除去 \(FeCl_3\) 中的 \(FeCl_2\)）
    ii. \(2Fe^{2+} + H_2O_2 + 2H^+ = 2Fe^{3+} + 2H_2O\)（除去 \(Fe^{3+}\) 中的 \(Fe^{2+}\)）
    iii. \(3Fe^{2+} + NO_3^- + 4H^+ = 3Fe^{3+} + NO\uparrow + 2H_2O\)（酸性条件下 \(Fe^{2+}\) 与 \(NO_3^-\) 不能大量共存）
    iv. \(6Fe^{2+} + Cr_2O_7^{2-} + 14H^+ = 6Fe^{3+} + 2Cr^{3+} + 7H_2O\)（除去污水中的 \(Cr_2O_7^{2-}\)）
    v. \(5Fe^{2+} + MnO_4^- + 8H^+ = 5Fe^{3+} + Mn^{2+} + 4H_2O\)（检验 \(Fe^{2+}\) 的还原性）
    ② 与还原剂反应（体现弱氧化性）
    \(Fe^{2+} + Zn = Zn^{2+} + Fe\)    		 (2) 氧化还原反应：与还原剂反应（体现较强氧化性）
    ① \(2Fe^{3+} + Fe = 3Fe^{2+}\)（除 \(Fe^{2+}\) 中的 \(Fe^{3+}\)）
    ② \(2Fe^{3+} + Cu = 2Fe^{2+} + Cu^{2+}\)（用 \(Fe^{3+}\) 腐蚀 \(Cu\)，制作印刷电路板）
    ③ \(2Fe^{3+} + S^{2-}\)（少量）\(= 2Fe^{2+} + S\downarrow\)
    ④ \(2Fe^{3+} + SO_3^{2-} + H_2O = 2Fe^{2+} + SO_4^{2-} + 2H^+\)
    ⑤ \(2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2\)
    (3) 显色反应
    \(Fe^{3+} + 3SCN^- \rightleftharpoons Fe(SCN)_3\)（红色溶液）

    ## D.铁及其化合物的转化关系
    a.\(Fe^{2+}\)、\(Fe^{3+}\) 的相互转化
      +2价 \(Fe\) 处在 \(Fe\) 的中间价态，既可以被氧化到+3价，也可以被还原到0价。
      +3价 \(Fe\) 也处在 \(Fe\) 的中间价态，既可以被极强氧化剂氧化成+6价，也可以被还原剂还原为+2价或0价。

      \(Fe^{2+} \xrightleftharpoons[\text{向溶液中加入 } Fe, Cu, H_2S \text{ (或 } HS^-, S^{2-}), SO_2 \text{ (或 } SO_3^{2-}, HSO_3^-), I^- \text{ 等}]{\text{向溶液中加入 } O_2, Cl_2, Br_2, H_2O_2, HNO_3, KMnO_4, K_2Cr_2O_7 \text{ 等}} Fe^{3+}\)

    b.\(Fe^{2+}\)、\(Fe^{3+}\) 的分离提纯
      (1) 除去 \(Fe^{2+}\) 中的 \(Fe^{3+}\)：加入还原剂，为了不引入新杂质，最好是 \(Fe\) 粉
      (2) 除去 \(Fe^{3+}\) 中的 \(Fe^{2+}\)：加入氧化剂，为了不引入新杂质，一般加 \(O_2\)、\(H_2O_2\) 等
