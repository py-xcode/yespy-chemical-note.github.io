    5.1 氯气的性质、用途、制备与检验

    A.氯元素¶

    a.自然界存在 Cl元素在自然界中以化合物的形式存在。

    b.氯原子的结构
      Cl原子结构示意图为，由此可知Cl原子容易得到1个电子，达到最外层8电子的稳定结构；也可以失去7个电子，达到最外层8电子的稳定结构。因此氯元素的化合价区间为[-1，+7]。Cl元素的稳定化合价为-1价，由此也可推出Cl₂易得到电子，具有强氧化性。
    c.物理性质 在常温常压下，Cl₂是黄绿色、有刺激性气味的有毒气体；易液化(液氯储存在钢瓶中)；可溶于水(在25℃时，1体积的水可溶解约2体积的氯气)；密度大于空气。
    d.化学性质
      0价是Cl的中间价态，所以Cl₂既有氧化性，又有还原性。但由于氯元素的稳价是-1价，所以Cl₂(0价)主要体现氧化性，能与大多数的还原剂反应。
      1. 与金属单质反应
      i.钠在\(\ce{Cl2}\)中剧烈燃烧，释放大量的热，生成白烟：\(\ce{2Na + Cl2 ->[\Delta] 2NaCl}\)。
      ii.铁在\(\ce{Cl2}\)中剧烈燃烧，释放大量的热，生成棕褐色的烟：\(\ce{2Fe + 3Cl2 ->[\Delta] 2FeCl3}\)。
      iii.铜在\(\ce{Cl2}\)中剧烈燃烧，释放大量的热，生成棕黄色的烟：\(\ce{Cu + Cl2 ->[\Delta] CuCl2}\)。

    注意

    i. \(\ce{Cl2}\)的氧化性强，与变价金属反应通常不存在量变引起质变，产物是高价金属氯化物。
    ii. 虽然\(\ce{Cl2}\)在加热时可以与铁单质反应，但常温下不反应，液氯可以用钢瓶储运。

      2. 与非金属单质反应
      i. \(\ce{H2}\) 在 \(\ce{Cl2}\) 中安静的燃烧，发出苍白色火焰，集气瓶口有白雾：\(\ce{H2 + Cl2 ->[点燃] 2HCl}\)。
      ii. \(\ce{P}\) 在 \(\ce{Cl2}\) 中燃烧，释放大量的热，生成白色的烟和雾：\(\ce{2P + 3Cl2 ->[\Delta] 2PCl3}\)(液体)、\(\ce{PCl3 + Cl2 <=> PCl5}\)(固体)。

    注意

    \(\ce{P}\) 与 \(\ce{Cl2}\) 的反应属于“连续反应”，很难直接用 \(\ce{P}\) 与 \(\ce{Cl2}\) 反应制备纯净的 \(\ce{PCl3}\)。连续反应是指产物会与反应物继续反应生成其他产物。

      3. 与水反应
      ①原理：\(\ce{H2O}\)中的所有元素均为稳价，\(\ce{Cl2}\)与\(\ce{H2O}\)发生氧化还原反应时，0价的\(\ce{Cl}\)既升高到+1价，又下降到-1价，该反应是歧化反应，且为可逆反应(可逆反应是指在相同条件下，反应既能正向进行，同时又能逆向进行的化学反应)。
      i. 化学方程式：\(\ce{Cl2 + H2O <=> HCl + HClO}\)
      ii. 离子方程式：\(\ce{Cl2 + H2O <=> H+ + Cl- + HClO}\)(书写离子方程式时，弱酸\(\ce{HClO}\)不拆)
      ②新制氯水与液氯的组成比较

    对象 新制氯水(混合物) 液氯(纯净物)
    组成 “三分四离”：\(\ce{H2O}\)>\(\ce{Cl2}\)>\(\ce{HClO}\)；\(\ce{H+}\)>\(\ce{Cl-}\)>\(\ce{ClO-}\)>\(\ce{OH-}\) \(\ce{Cl2}\)

    注意

    可逆反应不可能完全反应，不存在完全反应消失的物质，也就是说氯气溶于水之后，溶液中必定还有未反应的氯气。

      ③新制氯水合久置氯水的成分、性质比较
      
      4. 和碱反应（制取漂白液，漂白粉）
      
      

    注意

    1.制取漂白粉需要使用石灰乳而非澄清石灰水，并且注意温度是冷的。
    2.石灰乳在离子方程式中不可以拆写成离子。
    3.酸性：\(\ce{H2CO3 > HClO}\)。
    4.CO₂ 与 Ca(ClO)₂ 溶液反应存在量变引起质变，CO₂ 少生成 CaCO₃、HClO；CO₂ 多生成 Ca(HCO₃)₂、HClO。空气中的 CO₂ 浓度低，漂白粉在空气中变质生成 CaCO₃、HClO。
    5.Cl₂ 与碱反应是歧化反应，歧化反应一般遵循“邻价”规律。加热时 Cl 的化合价变化可能不遵循“邻价”规律（例：\(\ce{3Cl_{2} + 6NaOH\xlongequal{\Delta} 5NaCl + NaClO_{3} + 3H_{2}O}\)），而漂白粉和漂白液的有效成分都有 +1 价的 Cl，为了避免其生成其他价态的 Cl，应用冷的 NaOH、Ca(OH)₂。

      5. 与其他化合物反应

    反应对象 化学方程式 离子方程式
    与 H₂S 溶液反应 \(Cl_2 + H_2S = S\downarrow + 2HCl\) \(Cl_2 + H_2S = S\downarrow + 2H^+ + 2Cl^-\)
    与 SO₂ 水溶液反应 \(Cl_2 + SO_2 + 2H_2O = 2HCl + H_2SO_4\) \(Cl_2 + SO_2 + 2H_2O = 4H^+ + 2Cl^- + SO_4^{2-}\)
    与 KI 溶液反应 \(Cl_2 + 2KI = I_2 + 2KCl\) \(Cl_2 + 2I^- = I_2 + 2Cl^-\)
    与 KBr 溶液反应 \(Cl_2 + 2KBr = Br_2 + 2KCl\) \(Cl_2 + 2Br^- = Br_2 + 2Cl^-\)
    与 FeCl₂ 溶液反应 \(Cl_2 + 2FeCl_2 = 2FeCl_3\) \(Cl_2 + 2Fe^{2+} = 2Fe^{3+} + 2Cl^-\)
    与 NH₃ 反应 \(8NH_3 + 3Cl_2 = N_2 + 6NH_4Cl\)（\(NH_4Cl\) 是白色固体颗粒，其分散在空气中形成白烟，可用浓氨水检验运输液氯的管道是否漏气） （气相反应，无离子方程式）

    e.用途
      (1) 制盐酸：将 \(H_2\) 在 \(Cl_2\) 中燃烧生成的 \(HCl\) 气体溶于水即可制得盐酸。
      注：可燃物与氧化剂（如 \(O_2\)、\(Cl_2\)、\(N_2\)、\(CO_2\) 等）在一定条件发生发光、发热的氧化还原反应，称为燃烧。燃烧不一定需要 \(O_2\) 参加，如 \(H_2\)、\(Na\)、\(P\) 等在 \(Cl_2\) 中的燃烧；\(Mg\) 在 \(N_2\)、\(CO_2\) 中的燃烧等。煅烧、灼烧不是燃烧，如用坩埚煅烧 \(CaCO_3\) 是分解反应，不是燃烧；焰色试验灼烧铂丝没有发生化学变化。
      (2) 对自来水杀菌消毒：利用 \(Cl_2\) 以及 \(HClO\) 的强氧化性。
      注：①能对自来水杀菌消毒的还有 \(ClO_2\)、\(O_3\)、\(K_2FeO_4\) 等。
      ②明矾净水是利用铝离子与水反应的产物 \(Al(OH)_3\) 胶体使杂质沉淀，明矾不能对自来水杀菌消毒。
      (3) 冶炼金属或晶体硅
      (4) 合成有机物

    B.氯气的实验室制备¶

    a.原理
      化学方程式：\(MnO_2 + 4HCl(浓) \xlongequal{\Delta} MnCl_2 + Cl_2 \uparrow + 2H_2O\)
      离子方程式：\(MnO_2 + 4H^+ + 2Cl^- \xlongequal{\Delta} Mn^{2+} + Cl_2 \uparrow + 2H_2O\)
      注：
      (1) 由于 \(MnO_2\) 的氧化性不是特别强，所以需要使用浓盐酸并加热。
      (2) 该反应是部分氧化还原反应，4份 \(HCl\) 中，2份体现还原性(化合价升高)，2份体现酸性(化合价不变，生成盐)。氧化剂(\(MnO_2\))与还原剂(\(HCl\))的个数比为 1:2。
      (3) 若将 \(MnO_2\) 换成更强的氧化剂，则使用的盐酸浓度可以降低，且不需要加热。
      如用 \(KMnO_4\) 制备 \(Cl_2\) 的化学方程式为 \(2KMnO_4 + 16HCl = 2MnCl_2 + 2KCl + 5Cl_2 \uparrow + 8H_2O\)，
      离子方程式为 \(2MnO_4^- + 16H^+ + 10Cl^- = 2Mn^{2+} + 5Cl_2 \uparrow + 8H_2O\)。

    b.发生装置
      反应物的状态以及反应条件决定了发生装置使用的仪器。
    \(\ce{MnO2 + 4HCl(浓) \xlongequal{\Delta} MnCl2 + Cl2 \uparrow + 2H2O}\) \(\ce{2KMnO4 + 16HCl（浓） = 2MnCl2 + 2KCl + 5Cl2 \uparrow + 8H2O}\)
    （固液加热） （固液反应）

      注：
      (1) 用 \(\ce{MnO2}\) 制备 \(\ce{Cl2}\)，一定不要漏掉“酒精灯”。
      (2) 这两个装置均可用“液差法”检查气密性。

    c.除杂装置
    杂质 \(HCl\) 气体
    产生杂质的原因 盐酸具有挥发性
    杂质性质 \(HCl\) 气体极易溶于水、强酸性
    目标气体性质 \(Cl_2\) 可溶于水、水溶液显酸性、强氧化性
    除杂原理 利用饱和食盐水中的水溶解 \(HCl\) 气体，同时利用 \(NaCl\) 抑制 \(Cl_2\) 的溶解
    除杂试剂 饱和食盐水

    d.干燥装置
      \(Cl_2\) 水溶液显酸性，不能用碱性干燥剂(如碱石灰)干燥
    干燥剂 浓硫酸(液态) \(P_2O_5\) 或无水 \(CaCl_2\) (固态)
    装置

      注：
      (1) U形干燥管只能装固体干燥剂，若装液体干燥剂，会被生成的气体压入后续装置中。
      (2) 若水蒸气对后续实验无干扰，则无需干燥气体。
      (3) 验证氯气没有漂白性，氯气必须干燥，且有色物质也必须干燥。
      (4) 一般情况下，先除去其他杂质气体，后除水蒸气。
    e.收集装置
      常见的收集方法有排空气法和排液法。排空气法又有敞开体系的排空气法和密闭体系的排空气法。\(Cl_2\) 是有毒气体，应该用密闭体系的排空气法，便于进行尾气处理。
      若用排液法收集气体，则所选液体不能溶解目标气体。

      若气体有毒或易燃易爆，则需要尾气处理。尾气处理主要解决两个问题：一是用什么试剂吸收尾气；二是用什么仪器吸收尾气。

    C.次氯酸的性质¶

    a.从组成上 \(->\) \(HClO\) 具有酸性，且为一元弱酸。因为是弱酸，因此电离方程式需要用可逆符号。 \(\ce{HClO <=> H+ + ClO-}\)
      \(HClO\) 的酸性比 \(H_2CO_3\) 还弱，所以漂白粉和漂白液若敞开放置在空气中，会与空气中的 \(CO_2\) 发生反应而变质。
    b.从化合价上 \(->\) \(HClO\) 具有强氧化性、漂白性
      \(Cl\) 元素的稳价为 \(-1\) 价，\(HClO\) 中 \(Cl\) 为 \(+1\) 价，其化合价极易降低为 \(-1\) 价，得到电子，体现强氧化性。其强氧化性可以将大多数的有机色素氧化，使有机色素褪色，因此 \(HClO\) 又有漂白性。\(HClO\) 因具有强氧化性，还可用于杀菌消毒。
      注：要证明 \(Cl_2\) 无漂白性，而 \(HClO\) 才有漂白性，一般是将干燥氯气分别通入装有干燥有色布条、湿润有色布条的集气瓶中。干燥有色布条不褪色，湿润有色布条褪色。
    c.不稳定性
      光照新制氯水后，氯水的 \(pH\) 减小，且 \(Cl^-\)、\(O_2\) 浓度都增大，说明光照条件下 \(HClO\) 会分解产生 \(HCl\) 和 \(O_2\)，对应化学方程式为 \(2HClO \xrightarrow{光照} HCl + O_2 \uparrow\)。加热条件也会使 \(HClO\) 分解。
      用棕色瓶保存氯水，就是避免其见光分解。

    D.氯离子的检验¶

    \(Cl\) 元素的稳价为 \(-1\) 价，\(Cl^-\) 很难发生氧化还原反应；绝大多数氯化物易溶，如 \(KCl\)、\(CaCl_2\)、\(AlCl_3\) 等，但 \(AgCl\) 既难溶于水，又难溶于硝酸，因此常用稀 \(HNO_3\) 酸化的 \(AgNO_3\) 溶液检验 \(Cl^-\)。

    注：1. 由于 \(Ag^+\) 能与大多数的阴离子（如 \(CO_3^{2-}\)）形成沉淀，所以稀 \(HNO_3\) 的作用是排除其他阴离子的干扰（如将 \(CO_3^{2-}\) 转化为 \(CO_2\) 排出体系，以及氢氧根离子）。
    2.\(Br^-\)、\(I^-\) 也分别能与 \(HNO_3\) 酸化的 \(AgNO_3\) 溶液形成沉淀 \(AgBr\)、\(AgI\)，但这两种沉淀的颜色分别是淡黄色、黄色。所以描述检验 \(Cl^-\) 的现象时，记得描述沉淀的颜色为白色。
